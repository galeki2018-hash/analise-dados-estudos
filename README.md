# Projeto Python - Primeiros Passos

Este repositorio foi criado com o objetivo de organizar os primeiros estudos em Python, servindo como base para aprendizado, testes e evolucao gradual do codigo.

## 📁 Estrutura do Projeto

```
.
├── dados/               # Arquivos de dados (CSV, JSON, etc.)
├── notebooks/           # Jupyter Notebooks para estudos e testes
├── scripts/             # Roteiros, anotacoes e planejamentos
├── primeiros_passos.py  # Script inicial em Python
├── requirements.txt     # Dependencias do projeto
├── .env.example         # Exemplo de variaveis de ambiente
├── .gitignore           # Arquivos ignorados pelo Git
├── LICENSE              # Licenca do projeto
└── README.md            # Documentacao do projeto
```

## 🐍 Requisitos

- Python 3.8 ou superior
- Pip atualizado

## 📦 Instalacao

### 1. Clone o repositorio:

```bash
git clone https://github.com/galeki2018-hash/analise-dados-estudos.git
```

### 2. Acesse a pasta do projeto:

```bash
cd analise-dados-estudos
```

### 3. Instale as dependencias:

```bash
pip install -r requirements.txt
```

### 4. Crie o arquivo .env a partir do exemplo:

```bash
cp .env.example .env
```

## ▶️ Execucao

Para rodar o script inicial:

```bash
python primeiros_passos.py
```
